## 今天学会的知识

### 容器、行、列与 12 栅格

- `layui-container` 负责组织主要内容范围。
- `layui-row` 表示同一组横向布局，列应作为它的子元素。
- 列表示“占用这一行多少宽度”，默认没有边框，因此可能存在但肉眼看不到边界。
- 一行按 12 格计算：三等分使用 `4 + 4 + 4`，四等分使用 `3 + 3 + 3 + 3`。
- 已能根据列数自行推导 `md3`，而不只是照抄 `md4`。

### 响应式与间距

- `layui-col-xs12 layui-col-md4` 表示窄屏占满一行、达到 md 宽度后占四格。
- 同一个元素可以同时拥有多个 class，各 class 分别提供不同规则。
- `layui-col-space15` 写在行上，统一管理这一组列之间的间距。

### 栅格与卡片的分工

- 栅格列负责位置和宽度。
- `layui-card` 负责一张内容卡片的外观和内部结构。
- `layui-card-header` 与 `layui-card-body` 是卡片内部同级的标题区和正文区。
- 自定义 class 必须自己写 CSS；Layui class 必须以真实 CSS 或官方文档为依据，不能只凭名字猜测。

### 导航与下拉菜单

- `ul`、`li`、`a` 是 HTML 标签；`layui-nav`、`layui-nav-item`、`layui-this` 是 Layui class。
- `layui-this` 表示当前选中的导航项目。
- `dl.layui-nav-child` 必须写在对应主导航项目的 `li` 内，父子结构决定子菜单属于谁。
- 链接文字放进 `a` 后排版正常，是因为 Layui CSS 会按父子选择器为导航内的链接设置高度、内边距和可点击区域。
- `href="javascript:;"` 是当前练习的临时不跳转写法，不属于 Layui。

### DOM 与脚本执行顺序

- HTML 是源代码；DOM 是浏览器解析 HTML 后在内存中创建的对象树。
- `document.querySelector()` 查找的是已经创建的 DOM 对象，不是在硬盘文件中搜索文字。
- 浏览器从上向下解析 HTML。需要操作页面元素的 JavaScript 应在相关 DOM 建立后执行。
- 当前采用“CSS 放在 `head`，HTML 写在中间，JavaScript 放在 `</body>` 前”的清晰顺序。
- 已知道以后还可以学习 `defer`，但本阶段不增加额外写法。

### JavaScript 概念地图

- 变量给一个值起名；对象组织相关数据和功能；函数是一段可执行代码。
- 方法是对象中的函数；`()` 表示调用函数或方法。
- 模块描述代码负责的功能，对象描述它在 JavaScript 运行时的存在形式。Layui 常把模块以对象形式提供。
- `const layer = layui.layer` 中，左侧 `layer` 是变量，右侧表达式取得 `layer` 模块对象；这一行没有函数调用。
- 当前规则：默认使用 `const`，需要重新赋值时使用 `let`，能看懂但暂不主动使用规则较旧的 `var`。
- `layui.use(["element", "layer"], callback)` 可以一次准备多个模块；只有后续需要手动调用方法的模块才必须保存到局部变量。

## 教学方式调整

- “7 天”只作为观察学习节奏的周期，不作为赶课截止时间。
- 每天除分段学习外，保留一个从空文件完成的独立产出，用迁移结果判断是否真正会用。
- 抽象概念出现混乱时，暂停增加组件，用当前真实代码建立概念地图，再回到项目。
- 布局类知识先通过可见边界理解，理解后再去掉调试样式。
- 验收优先检查会影响运行和理解的错误，不因无关格式问题拖延。
