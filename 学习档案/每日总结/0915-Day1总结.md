## 今天学会的知识

- 知道 `class` 表示类别，可组合多个样式类；`id` 在页面中标识一个具体元素。
- 掌握 Layui 按钮的“基础类 + 修饰类”写法，如 `layui-btn layui-btn-danger`。
- 知道 `layui-btn-container` 用于组织一组相关按钮。

### Layui 引入

- CSS 负责外观，JavaScript 负责交互功能。
- 已从 CDN 引入切换到本地 2.13.9 文件。
- 能识别 CSS 加载失败与 JS 加载失败的大致表现。

### JavaScript 与 DOM

- `document.querySelector()` 和 `addEventListener()` 属于浏览器 DOM API，不属于 Layui。
- `layui.use()`、`layui.layer`、`layer.msg()` 属于 Layui。
- `document.querySelector("#id")` 在 DOM 中返回第一个符合 ID 选择器的元素。
- `addEventListener("click", callback)` 先登记事件，点击发生时再由浏览器调用回调函数。

### 方法、参数与对象

- 看到 `对象.方法()` 表示调用对象拥有的方法。
- `layer.msg` 的第一个参数是消息文字，第二个参数可以是配置对象。
- 配置对象使用 `{属性名: 值}`，多个属性用逗号分隔，例如 `icon` 和 `time`。
- 能区分函数代码块的 `{}` 与配置对象的 `{}`。

### use、匿名函数与回调

- `function () {}` 没有名字，因此是匿名函数；它被交给其他代码稍后调用时，同时承担回调函数的角色。
- 回调函数也可以有名字。“匿名”描述有没有名字，“回调”描述由谁调用。
- `startLayui` 表示函数本身；`startLayui()` 表示立即调用并得到返回值。
- `layui.use(startLayui)` 把函数交给 `use`；`layui.use(startLayui())` 会先执行函数，再把执行结果传给 `use`。
- 完整写法 `layui.use(["layer"], callback)` 的第一个参数是模块名数组，第二个参数是模块准备完成后的回调函数。
- 简写 `layui.use(callback)` 省略模块数组。Layui 2.13.9 会识别函数参数并使用内置模块集合。
