# 学习者画像

更新时间：2026-09-29（Day 3 综合练习通过后）。该文件只保存与本课程有关的信息，可随学习进展修改。

## 当前基础

- HTML：会写标准页面骨架、文本、列表、链接、图片、表格和基础表单。
- CSS：接触过选择器、常用属性、盒模型、浮动和定位；暂未形成独立还原页面的能力。
- JavaScript：已学习变量、基本数据类型、对象、运算符、条件判断，并完成 DOM 查找、点击事件、匿名函数/回调及配置对象的入门练习；能初步区分模块、对象、函数、方法、调用以及 const/let/var；数组遍历、JSON、异步和 Fetch/Ajax 尚未学习。
- Python：是当前相对熟悉的语言；能通过逐步拆解理解函数、闭包等概念。学过 FastAPI，但有些遗忘，衔接前需要短复习。
- 项目经验：知识点练习较多，完整前后端项目经验不足。

## 学习特点

- 更容易通过“先看结构，再逐层拆解，再亲手验证”理解知识。
- 对抽象术语容易在代码嵌套中混淆，但结合真实代码逐项标注后能准确复述。
- 希望知识形成体系，但需要防止长期停留在教程、迟迟不进入项目。
- 讲解偏好：不要用 Python 做类比；源码级细节觉得复杂，只要结论；"听不懂"时先讲做什么、为什么。
- 合适节奏：最小理论 → 小任务 → 报错/缺口 → 定点补课 → 总结共同规律。
- 每天需要一个从空文件完成的独立产出，用于确认能够迁移而不只是跟随讲义。
- 每天至少可投入 2 小时。
- Day 3 表单代码可以写出，但多个概念同时出现时难以建立因果链；学习者明确希望先复习旧内容，再把难点拆细，最后用独立练习串联。不能把“代码写对”当成“已经理解”。

## 本周策略

- 不暂停 Layui 去完整补 JavaScript；只补当天组件必需的 JS。
- 不要求默写类名和配置项；要求会查官网、会修改示例、会排错。
- 所有知识逐日汇入一个“学生管理后台”，为后续 MVC、Web API 和 CRUD 做准备。
- 先完成最小结果，再增加日期、上传、分页、选项卡等扩展功能。

## 当前主要缺口

1. 函数、回调函数和作用域仍需通过后续组件反复巩固。
2. 数组/对象数据的读取与遍历。
3. JSON、Fetch/Ajax 和前后端数据流。
4. 继续提升独立组织页面的熟练度，并养成 class 拼写、标签层级和脚本顺序自查习惯。
5. 表单提交链（`lay-submit` / `lay-filter` / `form.on` / `data.field` / `return false`）：已能在综合练习中写出并口头解释因果，回调嵌套与作用域仍需在后续组件中反复使用。
6. 属性与 class 拼写、括号配对、代码写错层：反复出现（`for`/`id`、`calss`、`from`），需养成写完自查的习惯。

## 长期目标

学完 Layui 第一阶段后，与 FastAPI 衔接，做前后端联通的小项目（先做学生管理系统）。前端课程中凡是和"数据从哪来、交给谁"有关的地方，都要为此铺垫。

## 结课标准

能借助官方文档独立拼出学生管理后台；能解释“按钮事件、表单数据、表格数据、接口请求”之间的关系。不以脱离文档默写为标准。
