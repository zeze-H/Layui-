# Layui 学习档案

这里仅保存学习路线和记录，不存放练习代码。练习代码由你亲手编写，放在项目根目录或对应章节目录中。

## 固定入口

- `当前任务.md`：每次只看这一份，完成后再进入下一课。
- `学习路线.md`：阶段路线和预期产出；7 天只是观察节奏，不是赶课期限。
- `学习进度.md`：我在检查代码后追加一条简短记录。
- `问题清单.md`：只记录反复出现或尚未解决的问题。
- `学习者画像.md`：根据练习代码维护的当前基础和教学策略。
- `协作规范.md`：我们之后共同遵守的教学方式。
- `每日总结/`：每天结束时保存当天成果、问题和下一次入口。
