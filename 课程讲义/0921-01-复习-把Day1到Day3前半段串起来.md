# 阶段复习 01：把 Day 1、Day 2、Day 3 前半段串起来

这不是新组件课。目标是先证明：你能看懂旧代码，并把已经学过的页面结构、按钮事件、表单外观组合到一起。做完后再拆 Day 3 的提交事件。**本课不写 `form.on`，也不提交表单。**

## 先看同一张页面中的三层职责

以“学生管理”页面为例：

| 要做的事                     | 由谁做          | 你写过的代码                                                              |
| ---------------------------- | --------------- | ------------------------------------------------------------------------- |
| 页面上有什么                 | HTML            | `h1`、`button`、`form`、`input`、`select`                       |
| 元素怎样排版、长什么样       | Layui CSS       | `layui-container`、`layui-row`、`layui-card`、`layui-form-item`   |
| 点击后做什么、下拉框如何渲染 | JS + Layui 模块 | `querySelector`、`addEventListener`、`layer.msg`、`form.render()` |

“表单有外观”和“表单已提交”是两回事。`form.render()` 负责渲染表单控件；它不会替你保存学生，也不等于 `form.on(...)`。

## 第一条线：从 HTML 元素到点击后的消息

对照 [Day 1 的按钮练习](../03-day1-巩固练习.html)：

```text
HTML：button id="addButton"  创建按钮、给它一个页面内的名字
JS：document.querySelector("#addButton")  找到已经创建的按钮 DOM 对象
JS：button.addEventListener("click", 函数)  登记点击后的工作
Layui：layer.msg("...")  点击后真正显示消息
```

`id="addButton"` 和 `"#addButton"` 文字对应；`#` 只出现在 CSS 选择器写法里。打开页面时运行的是“找按钮、登记事件”；点击时才运行消息代码。

## 第二条线：从行列到卡片

对照 [Day 2 的班级数据看板](../05-day2-综合练习.html)：

```text
layui-container                 内容区域
└── layui-row                  一组横向排列的列
    ├── layui-col-xs12 layui-col-md6  窄屏独占一行；宽屏占半行
    │   └── layui-card         列内部的内容外观
    └── layui-col-xs12 layui-col-md6  另一半
        └── layui-card
```

行是“把哪些列放在一组”，列是“在这一行占几格”，卡片是“列里面放什么样的内容”。宽屏一行 12 格，`6 + 6 = 12`；窄屏每列 12 格，所以两列会上下排列。列名不需要背，忘了可以看旧代码。

## 第三条线：表单结构与数据名字

对照 [Day 3 的表单](../06-day3-表单入门.html)：

```text
form.layui-form                  整张表单
└── layui-form-item             一项内容
    ├── label.layui-form-label  左侧说明
    └── layui-input-block       右侧控件区域
        └── input / select      真正输入或选择的控件
```

`label for="studentName"` 对应 `input id="studentName"`，负责点击标签时找到输入框。`name="studentName"` 是将来收集数据时用的字段名。`select` 中的 `<option value="male">男</option>`：用户看见“男”，程序得到 `male`。本课只复习这些关系，不读取表单数据。

下拉框使用 Layui 外观时，要等页面中的 `select` 存在、`layui.js` 已加载，再调用：

```javascript
layui.use(["form", "layer"], function () {
    const form = layui.form;
    const layer = layui.layer;
    form.render();
    // 后面才写找按钮和点击事件
});
```

`form` 和 `layer` 是两个模块对象，职责不同：前者处理表单控件，后者显示消息。`const form = layui.form` 是取得对象，`form.render()` 才是调用方法。`layui.use` 中的函数是在模块准备好之后执行的；按钮点击函数又是在用户点击之后执行的。**这是两个不同的等待时机。**

## 还有哪些旧知识要回想

- **Day 1 按钮样式和配置对象**：`layui-btn` 是基础样式，`layui-btn-danger` 之类是修饰样式；`layer.msg("文字", {icon: 1, time: 2000})` 的第二个参数是配置对象。复习页可以先用最简单的 `msg("文字")`，不必为了证明记忆力加配置。
- **Day 2 导航**：`ul.layui-nav` 包含 `li.layui-nav-item`，当前项可加 `layui-this`；子菜单 `dl.layui-nav-child` 要放在所属的 `li` 里面。导航是页面的另一块结构，和下面的栅格行不是同一层。导航的旧代码可以在综合练习时复用；当前 A 先不增加导航，以便集中检查布局和表单。
- **脚本位置**：页面元素在前，底部的 `layui.js` 和自己的脚本在后。`querySelector` 找的是浏览器已经建立的 DOM，不是在源文件中搜索文本。

## 本次复习产出：先做 A，验收后再做 B

当前复习实际使用 `08-复习-学生信息页.html`。可以翻看旧代码和本讲义，但练习内容由自己输入。

**A：先完成静态页面和下拉框。** 页面包含：本地 Layui CSS/JS、一个“学生管理”标题、一个 `layui-container`、一组 `layui-row layui-col-space15`、两个 `xs12 / md6` 列。第一列放“班级概况”卡片（例如“学生总数：45”），第二列放“新增学生”卡片；卡片内部是 `layui-form`，包含“姓名”文本框、“性别”下拉框和一个 `type="button"` 的“查看填写说明”按钮。下拉框选项用“请选择 / 男 / 女”，保留 `name` 与 `value`。页面底部用 `layui.use(["form", "layer"], ...)` 取得 `form` 并调用 `form.render()`。此时按钮点击还不做事。

A 的检查：宽屏两张卡片并排、窄屏上下排；点击“姓名”标签能聚焦输入框；性别下拉框能展开；页面没有控制台报错。做到这里就先发我“复习 A 验收”，不要自己继续加提交代码。

**B：A 通过后再做。** 给普通按钮加唯一 `id`，在同一个 `use` 回调里用 `querySelector` 找到它，`addEventListener("click", ...)` 中调用 `layer.msg("姓名和性别填写后，下一课学习提交")`。检查：打开页面不弹消息，点击按钮才弹。B 做完我们再进入表单提交拆解。

复习时不会考你默写 `layui-*` 类名；重点看你能否说清“结构、样式、行为”各由谁负责。资料：[Layui 表单文档](https://layui.dev/docs/2/form/)、[模块系统文档](https://layui.dev/docs/2/modules.html)。
