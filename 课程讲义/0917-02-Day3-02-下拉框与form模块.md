# Day 3-02：下拉框与 form 模块

## 一、这一节要实现什么

在“学生姓名、学生编号”下面增加一个学生性别下拉框：

```text
请选择学生性别
男
女
```

同时第一次使用 Layui 的 `form` 模块，让它渲染表单控件。

## 二、HTML 下拉框

下拉框使用 `select` 标签，选项使用 `option` 标签：

```html
<select id="studentGender" name="gender">
    <option value="">请选择学生性别</option>
    <option value="male">男</option>
    <option value="female">女</option>
</select>
```

结构是：

```text
select             整个下拉框
├── option         第一个选项
├── option         第二个选项
└── option         第三个选项
```

`select` 和 `option` 都是 HTML 标签，不是 Layui。

## 三、option 的文字与 value

```html
<option value="male">男</option>
```

这里有两份内容：

```text
男       用户在页面中看到的文字
male     程序收集到的实际值
```

如果用户选择“男”，以后表单数据类似：

```text
gender: male
```

第一个选项使用空字符串：

```html
<option value="">请选择学生性别</option>
```

它表示用户还没有选择真正的性别值。后面学习必填验证时，空值会很有用。

## 四、下拉框放在哪一层

下拉框仍然是一项表单内容，因此沿用上一节结构：

```html
<div class="layui-form-item">
    <label class="layui-form-label" for="studentGender">学生性别</label>
    <div class="layui-input-block">
        <select id="studentGender" name="gender">
            <option value="">请选择学生性别</option>
            <option value="male">男</option>
            <option value="female">女</option>
        </select>
    </div>
</div>
```

变化的只是 `input-block` 内部控件：

```text
上一节：input-block → input
这一节：input-block → select → option
```

## 五、为什么 select 不写 layui-input

文本框使用：

```html
<input class="layui-input">
```

下拉框不直接使用 `layui-input`。当它位于 `layui-form` 内，并由 `form` 模块渲染时，Layui 会按照下拉框组件的规则处理它。

因此不要把所有输入控件都机械地加上 `layui-input`。

## 六、加载 form 模块

在页面内容之后、`</body>` 前引入本地 JavaScript：

```html
<script src="./layui-v2.13.9/layui/layui.js"></script>
<script>
    layui.use(["form"], function () {
        const form = layui.form;
        form.render();
    });
</script>
```

逐行理解：

```text
layui.use(["form"], callback)
让 Layui 准备 form 模块，准备好后调用回调函数。

const form = layui.form
取得 form 模块对象，保存到变量 form。

form.render()
调用 form 模块对象的 render 方法，渲染页面中的 Layui 表单控件。
```

这次变量 `form` 不是只保存不用，因为下一行确实调用了它的 `render()` 方法。

执行顺序：

```text
浏览器先创建 form、input、select 等 DOM
→ 加载 layui.js
→ use 准备 form 模块
→ 回调函数执行
→ form.render() 扫描并渲染表单控件
```
