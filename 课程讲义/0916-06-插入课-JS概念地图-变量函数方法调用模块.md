# 插入课：JavaScript 概念地图

这节先暂停增加 Layui 组件，专门整理 `var / let / const`、变量、对象、函数、方法、调用和模块。它们不是互相独立的生词，而是同一套关系中的不同部分。

## 一、先看总关系

```text
变量：给一个值起名字
对象：把一组相关的数据和功能装在一起
函数：一段可以执行的代码
方法：放在对象里面的函数
调用：使用 () 让函数真正执行
模块：按某个功能整理好的一组代码，通常会提供对象和方法
```

关系图：

```text
Layui 库
└── layer 模块对象
    ├── msg 方法（本质是函数）
    ├── alert 方法（本质是函数）
    └── confirm 方法（本质是函数）
```

所以：**方法也是函数**，只是它属于某个对象，需要通过 `对象.方法()` 使用。

## 二、变量是什么

变量是一个名字，用来保存或者指向某个值：

```javascript
const element = layui.element;
```

这句话可以读成：

```text
创建一个名为 element 的变量
让它保存 layui.element 这个模块对象
```

左边的 `element` 是我们自己起的变量名；右边的 `layui.element` 是 `layui` 对象上的一个属性。

## 三、var、let、const 的区别

三者都可以声明变量，但规则不同。

### const：变量不能重新赋值

```javascript
const layer = layui.layer;
```

之后不能让 `layer` 改为另一个值：

```javascript
layer = "其他内容"; // 报错
```

当前学习中，如果变量不需要重新赋值，默认使用 `const`。

### let：变量以后可以重新赋值

```javascript
let count = 0;
count = 1;
count = 2;
```

计数器、会变化的状态等，适合使用 `let`。

### var：旧式变量声明

```javascript
var count = 0;
```

`var` 也能重新赋值，但它使用较旧的作用域规则，还允许在同一作用域重复声明，容易产生不直观的结果：

```javascript
var count = 0;
var count = 10; // 不报错
```

现阶段的使用原则：

```text
默认用 const
确实需要重新赋值时用 let
自己写的新代码暂时不用 var，但要能看懂旧代码中的 var
```

更完整的作用域、提升机制以后学到相关场景时再讲，现在不需要硬记。

## 四、函数是什么

函数是一段暂时保存起来、可以在需要时执行的代码：

```javascript
function sayHello() {
    console.log("你好");
}
```

这里只是定义函数，还没有执行函数。

```javascript
sayHello();
```

出现 `()` 才是在调用它，函数体里的代码此时才执行。

## 五、匿名函数和回调函数

```javascript
function () {
    console.log("模块准备好了");
}
```

它没有函数名，所以是**匿名函数**。

```javascript
layui.use(["element"], function () {
    console.log("模块准备好了");
});
```

这个匿名函数被当作参数交给 `use`，等待 `use` 在合适时机调用，因此它同时也是**回调函数**。

```text
匿名函数：描述它有没有名字
回调函数：描述它被交给别人、以后由别人调用的用途
```

同一个函数可以同时是匿名函数和回调函数。

## 六、方法是什么

方法是属于某个对象的函数：

```javascript
layer.msg("保存成功");
```

拆开看：

```text
layer      对象（这里指向 Layui 的 layer 模块对象）
msg        layer 对象提供的方法
()         调用这个方法
"保存成功" 传给方法的参数
```

普通函数与方法的区别主要在写法：

```javascript
sayHello();             // 调用普通函数
layer.msg("你好");      // 调用对象的方法
```

它们最终都是执行函数代码。

## 七、“获取”和“调用”怎么区分

判断时先看有没有执行用的小括号：

```javascript
layui.element        // 获取属性，没有调用
layer.msg            // 获取 msg 这个函数本身，没有调用
layer.msg("你好")    // 调用 msg 方法
sayHello             // 取得 sayHello 函数本身，没有调用
sayHello()           // 调用 sayHello 函数
```

注意：代码中可能还有数组的 `[]` 或配置对象的 `{}`，它们不是函数调用。函数调用看的是函数名后面的 `()`。

## 八、模块是什么

模块可以先理解成：**围绕一种功能整理好的一包代码**。

例如 Layui：

```text
layer 模块：弹层相关功能
element 模块：导航、选项卡等元素交互
form 模块：表单相关功能
table 模块：数据表格相关功能
```

模块通常会提供一个对象，对象里面再提供方法：

```javascript
const layer = layui.layer; // 获取 layer 模块对象
layer.msg("成功");         // 调用模块对象的 msg 方法
```

因此“模块”和“对象”不是互相排斥的说法：

```text
从用途看，它是 layer 模块
从 JavaScript 的值类型和使用方式看，拿到的是一个对象
```

## 九、把真实代码完整拆开

### 例 1：查找按钮

```javascript
const startButton = document.querySelector("#startButton");
```

```text
const          声明一个不重新赋值的变量
startButton    自己起的变量名
document       浏览器提供的 DOM 对象
querySelector  document 对象的方法
(...)          调用该方法
返回结果       保存进 startButton
```

### 例 2：监听点击

```javascript
startButton.addEventListener("click", function () {
    layer.msg("开始学习");
});
```

```text
startButton       DOM 元素对象
addEventListener  这个对象的方法
(...)             现在调用 addEventListener
"click"          第一个参数：事件类型
function...       第二个参数：匿名回调函数
layer.msg(...)    点击发生后才调用的方法
```

### 例 3：加载 element 模块

```javascript
layui.use(["element"], function () {
    const element = layui.element;
});
```

```text
layui             Layui 提供的总对象
use               layui 对象的方法
use(...)          调用 use
["element"]       第一个参数：需要的模块名数组
function...       第二个参数：模块准备好后执行的回调函数
layui.element     获取 element 模块对象，没有调用
const element     用变量保存这个模块对象
```
