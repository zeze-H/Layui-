# 已学内容复习总览：页面结构与连接规则

这份讲义只用于忘记之后快速找回结构，不是新课，也不要求背诵。先看本页，再回到 `学习档案/当前任务.md` 做一个小任务。

## 一张网页的三个区域

```text
head
└── 引入 layui.css：让 layui-* class 产生样式

body
├── 导航、标题、卡片、表单等 HTML
└── 页面底部
    ├── 引入 layui.js：提供 Layui 的 JavaScript 功能
    └── 自己的 JavaScript：准备模块、查找元素、登记事件
```

推荐顺序：CSS 放在 `head`；页面内容写在 `body`；`layui.js` 和自己的脚本放在页面内容之后。

## 导航的结构

```html
<ul class="layui-nav">
    <li class="layui-nav-item layui-this">
        <a href="javascript:;">首页</a>
    </li>
    <li class="layui-nav-item">
        <a href="javascript:;">学生管理</a>
        <dl class="layui-nav-child">
            <dd><a href="javascript:;">学生列表</a></dd>
            <dd><a href="javascript:;">新增学生</a></dd>
        </dl>
    </li>
</ul>
```

```text
ul.layui-nav
└── li.layui-nav-item
    ├── a：主项目
    └── dl.layui-nav-child：属于该项目的子菜单
        └── dd → a：子项目
```

`layui-this` 表示当前选中项。子菜单必须写在它所属的 `li` 里面。

## 布局与卡片的结构

```html
<div class="layui-container">
    <div class="layui-row layui-col-space15">
        <div class="layui-col-xs12 layui-col-md6">
            <div class="layui-card">
                <div class="layui-card-header">卡片标题</div>
                <div class="layui-card-body">卡片内容</div>
            </div>
        </div>
    </div>
</div>
```

```text
container：页面主体范围
└── row：同一组横向排列的列
    └── col：这一列在不同屏幕上占多少宽度
        └── card：内容外观
            ├── card-header：标题区
            └── card-body：正文区
```

`xs12` 表示窄屏占满 12 格；`md6` 表示中等及以上宽度占 6 格。两个 `md6` 正好组成一整行。

## 表单的结构

```html
<form class="layui-form">
    <div class="layui-form-item">
        <label class="layui-form-label" for="studentName">学生姓名</label>
        <div class="layui-input-block">
            <input
                type="text"
                id="studentName"
                name="studentName"
                class="layui-input"
            >
        </div>
    </div>
</form>
```

```text
form.layui-form：整张表单
└── layui-form-item：一项内容
    ├── label.layui-form-label：左侧说明
    └── layui-input-block：右侧控件区域
        └── input / select / button：实际控件
```

`label for="studentName"` 对应 `input id="studentName"`。`name="studentName"` 是将来收集数据时使用的字段名。

下拉框的可见文字和程序值可以不同：

```html
<select name="gender" id="studentGender">
    <option value="">请选择学生性别</option>
    <option value="male">男</option>
    <option value="female">女</option>
</select>
```

用户看见“男”，程序读到 `male`。以后形成数据对象时，`name` 提供键，当前输入或选中的 `value` 提供值：

```javascript
{
    studentName: "张三",
    gender: "male"
}
```

## `id`、`class`、`#` 和 `.`

| 位置            | 写法                             | 含义                                |
| --------------- | -------------------------------- | ----------------------------------- |
| HTML 属性       | `id="helpButton"`              | 给一个元素唯一标识，不写`#`       |
| HTML 属性       | `class="layui-btn"`            | 给元素一个或多个类别，不写`.`     |
| CSS 选择器      | `#helpButton`                  | `#` 表示按 id 查找                |
| CSS 选择器      | `.layui-btn`                   | `.` 表示按 class 查找             |
| JavaScript 查找 | `querySelector("#helpButton")` | 参数使用 CSS 选择器规则             |
| JavaScript 对象 | `layui.layer`                  | 从`layui` 对象读取 `layer` 属性 |
| JavaScript 方法 | `layer.msg()`                  | 调用`layer` 对象的 `msg` 方法   |

HTML 中写：

```html
<button id="helpButton" class="layui-btn">查看填写说明</button>
```

JavaScript 中按 id 查找：

```javascript
const helpButton = document.querySelector("#helpButton");
```

`querySelector` 的参数是选择器，所以 id 前面写 `#`。`document.querySelector` 中间的点不是选择器，它表示“使用 document 对象里的 querySelector 方法”。

## 模块对象、变量和方法

```text
layui：Layui 总对象
├── form：表单模块对象
│   ├── render()：渲染表单控件
│   └── on()：登记表单事件
└── layer：弹层模块对象
    └── msg()：显示短消息
```

常见写法：

```javascript
layui.use(["form", "layer"], function () {
    const form = layui.form;
    const layer = layui.layer;

    form.render();
    layer.msg("提示文字");
});
```

`const layer = layui.layer` 没有调用函数，只是给模块对象起一个较短的局部名字。它不是强制步骤，下面也能工作：

```javascript
layui.layer.msg("提示文字");
```

先保存到变量的好处是代码更短、职责更清楚，并且后续可以多次使用同一个模块对象。

## 普通按钮点击的完整连接

```html
<button type="button" id="helpButton" class="layui-btn">查看填写说明</button>
```

```javascript
const helpButton = document.querySelector("#helpButton");

helpButton.addEventListener("click", function () {
    layer.msg("姓名和性别填写后，下一课学习提交");
});
```

执行顺序：

```text
HTML 创建按钮并给出 id
→ querySelector 找到按钮 DOM 对象
→ addEventListener 登记 click 回调
→ 用户点击按钮
→ 浏览器调用回调函数
→ layer.msg 显示消息
```

## 忘记后怎样重新开始

1. 先找外层结构：`container → row → col → card`。
2. 再看卡片内部是普通内容还是 `form`。
3. 表单中逐项检查：`form-item → label + input-block → 控件`。
4. 需要控制具体元素时，先看 HTML 的 `id`，再看 JS 的 `#id` 是否对应。
5. 最后看脚本：模块是否准备、对象是否取得、事件是否登记、方法是否在正确时机调用。

学到哪一步，看 `学习档案/当前任务.md`。
