# Day 1-07：layui.use 与嵌套结构

## 一、先看完整结构，不急着看细节

```javascript
layui.use(function () {
    var layer = layui.layer;
    var button = document.querySelector("#startButton");

    button.addEventListener("click", function () {
        layer.msg("开始今天的学习", {
            icon: 6,
            time: 3000
        });
    });
});
```

它看起来嵌套很多，实际上只有三个阶段：

```text
第一层：Layui 准备完成
    第二层：等待按钮点击
        第三层：点击后显示消息
```

## 二、点号表示什么

```javascript
layui.use
button.addEventListener
layer.msg
```

共同形式都是：

```text
对象.它拥有的属性或方法
```

- `layui.use`：使用 `layui` 对象的 `use` 方法。
- `button.addEventListener`：使用按钮对象的事件监听方法。
- `layer.msg`：使用弹层对象的消息方法。

看到 `()` 才表示调用方法：

```javascript
layui.use(...)
layer.msg(...)
```

## 三、layui.use 到底做什么

```javascript
layui.use(function () {
    // 使用 Layui 的代码
});
```

`layui.use` 负责准备 Layui 模块。模块准备完成后，它需要执行我们的代码，因此我们要告诉它“准备完成后做什么”。

先看一种比较长、但容易理解的写法：

```javascript
function startLayui() {
    var layer = layui.layer;
    layer.msg("Layui 已经准备好了");
}

layui.use(startLayui);
```

第一部分定义了一个名叫 `startLayui` 的函数。函数在 JavaScript 中不仅可以执行，也可以像数字、字符串一样保存在变量中或作为参数传递。

```javascript
startLayui
```

只有函数名，没有圆括号，得到的是“函数本身”。可以把它想成一张还没有执行的操作清单。

```javascript
startLayui()
```

函数名后面有圆括号，表示现在按照清单执行里面的代码。

所以：

```javascript
layui.use(startLayui);
```

这里把函数本身作为参数传给 `layui.use`。`use` 收到的是函数，所以它可以在 Layui 模块准备好后调用这个函数。

对比一个通常错误的写法：

```javascript
layui.use(startLayui());
```

JavaScript 在调用外层方法之前，会先计算圆括号里的参数。因此执行顺序变成：

```text
1. 立即执行 startLayui()
2. startLayui 没有 return，执行结果是 undefined
3. 再执行 layui.use(undefined)
```

这样 `startLayui` 不是由 Layui 在合适的时机调用，而是在 `use` 收到它之前就已经执行完了。

所以两者真正的区别不是简单的“执行和不执行”，而是“由谁决定执行时机”：

```text
layui.use(startLayui)    把函数交给 use，由 use 调用
layui.use(startLayui())  自己立即调用函数，把执行结果交给 use
```

如果这个函数只在这里使用一次，可以省略函数名，直接写在 `use` 的圆括号中：

```javascript
layui.use(function () {
    var layer = layui.layer;
    layer.msg("Layui 已经准备好了");
});
```

上面两种写法的作用相同：

```text
写法一：先单独定义 startLayui，再把 startLayui 交给 use
写法二：直接在 use 的参数位置创建一个没有名字的函数
```

没有名字的函数叫匿名函数。一个函数被交给其他代码、之后由其他代码调用时，它承担的是回调函数的角色。

### use 的两个参数是什么

完整写法是：

```javascript
layui.use(["layer", "form"], function () {
    var layer = layui.layer;
    var form = layui.form;
});
```

圆括号中有两个参数，使用逗号分隔：

```text
第一个参数：["layer", "form"]
第二个参数：function () { ... }
```

第一个参数使用方括号 `[]`，表示一个数组。数组可以按顺序放多个值：

```javascript
["layer", "form"]
```

这里放了两个字符串，告诉 `use`：本段代码需要 `layer` 和 `form` 两个模块。现在只需要认识这种写法，不学习数组操作。

第二个参数是回调函数，告诉 `use`：模块准备好之后执行这里的代码。

因此完整流程是：

```text
use 读取模块名数组
→ 准备 layer 和 form
→ 准备完成
→ use 调用第二个参数中的函数
```

### 为什么当前代码可以省略模块数组

当前写法是：

```javascript
layui.use(function () {
    var layer = layui.layer;
});
```

这里传入的第一个参数直接就是函数。Layui 2.13.9 的 `use` 会判断参数类型：发现第一个参数是函数后，就把它当成回调函数，并使用内置模块集合。

可以先把它理解为 Layui 提供的方便写法：

```text
完整写法：明确列出需要哪些模块，再传回调函数
简写方式：省略模块数组，直接传回调函数
```

我们入门示例沿用官网的简写，先把注意力放在组件使用上。以后拆分项目和按需加载时，再使用明确模块数组的写法。

## 四、为什么里面还有一个 function

```javascript
button.addEventListener("click", function () {
    layer.msg("你好");
});
```

这一次函数交给的是浏览器：

```text
我们：这是点击后要执行的函数
浏览器：按钮发生 click 时，我来调用它
```

两个回调函数的触发条件不同：

```text
layui.use 的回调      Layui 准备好后执行
click 事件的回调      用户点击按钮后执行
```

## 五、为什么要嵌套

点击事件需要使用 `layer`，所以它写在能够取得 `layer` 的 `layui.use` 回调里面：

```text
layui.use 回调的范围
├── layer 变量
├── button 变量
└── click 回调
    └── 可以使用外面的 layer 和 button
```

嵌套不是为了让代码显得复杂，而是在表达先后关系和可使用范围。

## 六、为什么当前 JavaScript 写在一起

不是所有 JavaScript 永远都必须写在一起。当前把相关代码放进同一个 `layui.use`，有三个原因。

### 原因 1：都要等 Layui 准备好

`layer` 来自 Layui。取得 `layer` 和使用 `layer` 的代码，都放在 Layui 准备完成后执行最清楚。

### 原因 2：里面的代码可以共享变量

```javascript
layui.use(function () {
    var layer = layui.layer;

    button.addEventListener("click", function () {
        layer.msg("你好");
    });
});
```

点击回调写在外层函数里面，因此可以使用外层创建的 `layer` 变量。

如果把相关代码随意拆到不同位置，可能出现：某处没有 `layer`、按钮还没创建、执行顺序不清楚等问题。

### 原因 3：这里属于同一段页面初始化逻辑

```text
取得模块
→ 找到页面元素
→ 给元素绑定事件
```

它们共同完成这个页面的初始化，放在一起便于阅读。

项目变大以后，我们会把 JavaScript 拆到独立 `.js` 文件，甚至按页面或功能拆分。拆分的是文件和功能，相关代码仍然需要正确的执行顺序和作用范围。

## 七、花括号为什么有不同含义

### 函数的花括号

```javascript
function () {
    要执行的代码
}
```

表示函数的代码块。

### 对象的花括号

```javascript
{
    icon: 6,
    time: 3000
}
```

表示一个配置对象。

判断方式：`function` 后面的 `{}` 是代码块；作为方法参数传入、里面写 `属性名: 值` 的 `{}` 是对象。

## 八、括号配对阅读法

看到复杂代码时：

1. 先找到最外层方法：`layui.use(`。
2. 找到和它配对的最后一个 `);`。
3. 再看里面的 `addEventListener(` 及其配对 `);`。
4. 最后看最内层的 `layer.msg(` 及其配对 `);`。

不要一次横着读完所有符号，要从外层向内层读。

我们采用循环加深：

```text

```
