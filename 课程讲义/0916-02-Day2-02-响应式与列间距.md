# Day 2-02：响应式列与列间距

## 一、这一节解决什么问题

上一节的三个 `layui-col-md4` 在较宽屏幕上并排显示。但后台页面也可能在手机或较窄窗口中打开。

我们希望同一份 HTML 自动变成：

```text
较宽屏幕：三个卡片并排，每个占 4/12
较窄屏幕：三个卡片上下排列，每个占 12/12
```

这叫**响应式布局**：页面根据屏幕宽度选择不同的排列规则。

## 二、一个元素可以同时拥有多个 class

```html
<div class="layui-col-xs12 layui-col-md4">
```

这里不是两个元素，而是同一个 `div` 同时拥有两条宽度规则：

```text
layui-col-xs12：较窄屏幕时占 12 格，也就是整行
layui-col-md4：达到 md 宽度时占 4 格，也就是三分之一行
```

可以把它读成：

> 默认一张卡片占满一行；屏幕足够宽时，一张卡片改为占三分之一行。

`xs` 和 `md` 是屏幕宽度级别，不是具体设备名称。本阶段先掌握这两个：

```text
xs：最小宽度规则
md：中等宽度规则
```

## 三、为什么要同时写 xs12 和 md4

只写 `md4`，宽屏时可以三等分，但没有清楚表达窄屏时希望它占多少格。

同时写：

```html
class="layui-col-xs12 layui-col-md4"
```

相当于把两种情况都明确告诉 Layui，代码的意图更完整，也更容易控制。

## 四、给列增加间距

三个列紧贴在一起时，不像三个独立卡片。Layui 可以在行上添加列间距类：

```html
<div class="layui-row layui-col-space15">
```

拆开读：

```text
layui-row          这是一行
layui-col-space15  这一行中的列使用 15px 间距
```

间距规则写在行上，是因为它管理的是这一整组列之间的距离。

## 五、完整结构

```html
<div class="layui-row layui-col-space15">
    <div class="layui-col-xs12 layui-col-md4">
        <div class="demo-box">学生总数</div>
    </div>
    <div class="layui-col-xs12 layui-col-md4">
        <div class="demo-box">今日新增</div>
    </div>
    <div class="layui-col-xs12 layui-col-md4">
        <div class="demo-box">待处理申请</div>
    </div>
</div>
```

父子关系没有变化：

```text
行：负责这一组列以及列间距
列：负责不同屏幕宽度下占几格
内容盒子：负责背景、内边距和文字
```

3. 保留三个 `demo-box` 和帮助观察的样式。
4. 刷新页面，然后慢慢缩窄浏览器窗口。

这一节不写 JavaScript。验收重点不是背类名，而是能说清：`xs12`、`md4` 和 `space15` 分别控制什么。
