# Day 1-06：CDN 与本地资源

## 两种引入方式

当前代码使用 CDN：

```html
<link href="//unpkg.com/layui@2.13.9/dist/css/layui.css" rel="stylesheet">
<script src="//unpkg.com/layui@2.13.9/dist/layui.js"></script>
```

CDN 是网上的公共文件服务器。优点是方便，缺点是网络不可用时可能加载失败。

项目中已经下载了 Layui，因此也可以使用本地文件：

```html
<link href="./layui-v2.13.9/layui/css/layui.css" rel="stylesheet">
<script src="./layui-v2.13.9/layui/layui.js"></script>
```

## 路径怎么读

```text
./                       从当前 HTML 所在文件夹开始
layui-v2.13.9/           进入版本目录
layui/                   进入 Layui 发布目录
css/layui.css            CSS 文件
layui.js                 JavaScript 文件
```

HTML 文件在项目根目录，所以以上相对路径成立。移动 HTML 后，相对路径可能需要改变。

## CSS 和 JS 加载失败的表现

- CSS 失败：按钮还在，但恢复成浏览器默认外观。
- JS 失败：`layui` 不存在，弹层无法运行，控制台通常出现 `layui is not defined`。

## 练习

把现有两条 CDN 地址换成本地路径，其他代码不动。刷新后确认按钮样式和点击弹层仍然正常。
