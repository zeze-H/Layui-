# Day 4-01：layer.confirm（询问框）

## 它做什么

弹出一个带"确定 / 取消"的询问框，用户必须选一个。用来防止误操作，比如保存、删除前先问一句。

| | `layer.msg` | `layer.confirm` |
| --- | --- | --- |
| 作用 | 通知，几秒后自己消失 | 询问，等用户回答 |
| 用户能做什么 | 只能看 | 点确定或取消 |

`confirm` 是 Layui 的 `layer` 模块提供的 JS 功能，不是 CSS。

## 写法

```js
layer.confirm("确定要删除吗?", function (index) {   // 点"确定"时才调用
    layer.msg("已删除");
    layer.close(index);                             // 确定后要自己关
});
```

- 第 1 项：提示文字。
- 第 2 项：点"确定"时 layer 调用的函数。
- 第 3 项（可选）：点"取消"时 layer 调用的函数；不写，取消就直接关框。

## 三个要点

1. **括号内外时机不同**：交给 `confirm` 的函数不会马上执行，只有点"确定"才由 layer 调用；写在括号外的代码，弹出确认框后马上继续执行。
   - 本课踩过的错：把 `layer.msg("已收到表单数据")` 写在 `confirm` 括号外，它马上执行，并把刚弹出的确认框关掉（`msg` 和 `confirm` 同属 dialog 类弹层，新弹层出现时会关掉旧的）。
2. **`index` 是弹层编号**：页面可能同时有多个弹层，layer 给每个一个编号，点确定时把编号传给你的函数；`layer.close(index)` 关掉这一个。名字随便取，但括号里的名字要和 `close(...)` 里一致。
3. **点取消时确定函数没有被调用**，不是"被结束"。`studentInfo` 在弹出确认框后很快就执行完了，不等点击。

## return 与 return false

- `return` 结束**它所在的那个函数**，同函数里后面的代码不再执行。
- 里层函数里的 `return` 不影响外层函数。
- `return false` 写在 `studentInfo` 最外层：Layui 把返回值交给浏览器，浏览器就取消默认提交（不跳转、不刷新）。
- 跳转本身是浏览器对表单提交按钮的默认行为，不是 Layui 或某个方法决定的。
- 删掉 `return false` 后，点提交会看到地址栏出现 `?studentName=...`。

## 里层函数能用外层变量

确定函数里可以直接用 `studentInfo` 的参数 `data`，所以 `console.log(data.field)` 可以写在确定函数里，只在确认保存时才打印。
