# Layui 本地课程讲义

这些讲义由老师根据 Layui 2.13.9 官方文档重新整理，使用适合当前基础的中文讲解，不是官网原文副本。

文件名统一使用 `MMDD-课次-标题.md`，例如 `0921-03-...`。按文件名排序就是学习顺序；`00-README.md` 是本页，带“旧版”的文件只作历史对照。

教学顺序固定为：

1. 先解释这个知识解决什么问题；
2. 再逐行讲语法和原因；
3. 老师展示最小示例；
4. 学生亲手输入一个很小的练习；
5. 老师读取代码并反馈；
6. 掌握后才进入下一小节。
