## 教学节奏

1. 先讲清一个概念解决什么问题。
2. 只展示当前需要的最小代码。
3. 学生亲手完成一个很小的修改。
4. 老师读取代码并只检查本步重点。
5. 理解并验收后再进入下一小节。
