# Day 2-03：卡片与布局分工

## 一、为什么还需要卡片

上一节已经解决了“内容放在哪里、占多宽”：

```text
row 负责一横排
col 负责这一排中的宽度
```

但是 `row` 和 `col` 只负责布局，不负责把内容做成后台中常见的白色信息卡片。

这一节在每个列里面放一个 Layui 卡片：

```text
列：决定卡片的位置和宽度
卡片：负责标题区和内容区的外观
```

## 二、Layui 卡片的结构

一个卡片由三层组成：

```html
<div class="layui-card">
    <div class="layui-card-header">学生总数</div>
    <div class="layui-card-body">128 人</div>
</div>
```

逐层理解：

```text
layui-card         整张卡片
layui-card-header  卡片的标题区域
layui-card-body    卡片的主要内容区域
```

它们是父子关系，不是三个互不相关的样式：

```text
layui-card
├── layui-card-header
└── layui-card-body
```

## 三、卡片为什么放在列里面

完整关系是：

```text
layui-container
└── layui-row
    ├── layui-col-*
    │   └── layui-card
    │       ├── layui-card-header
    │       └── layui-card-body
    ├── layui-col-*
    │   └── layui-card
    └── layui-col-*
        └── layui-card
```

如果把 `layui-card` 比作一件家具：

- 栅格列决定家具放在哪个房间、能占多宽；
- 卡片决定这件家具内部是什么样子。

以后换成表格、表单或者图表，外面的栅格仍然可以不变。

## 四、Layui class 和自定义 class 的区别

```html
<div class="layui-card">
```

`layui-card` 是 Layui 已经写好的样式类。

```html
<h1 class="dashboard-title">
```

`dashboard-title` 是我们自己起的名字，需要自己写 CSS：

```css
.dashboard-title {
    margin: 20px 0;
}
```

不要根据名字猜一个 class 是否有效：Layui class 要以本地 CSS 或官方文档中真实存在的类名为准；自定义 class 必须由我们自己定义样式。
