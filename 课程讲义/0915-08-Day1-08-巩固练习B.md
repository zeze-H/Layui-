# Day 1-08：巩固练习 B

## 目标

从空文件重新搭建一个最小的学生管理操作区，验证能否复用 Day 1 的知识。

可以查看课程讲义，但不要复制 `02-页面元素与点击事件.html` 的整段代码。

## B1：页面结构与本地资源

新建文件：

```text
3.Day1巩固练习.html
```

亲手完成：

1. 写出 HTML 基本骨架。
2. 页面标题 `<title>` 写“学生管理练习”。
3. 使用本地路径引入 `layui.css` 和 `layui.js`。
4. 正文写一级标题“学生管理”。
5. 创建一个 Layui 按钮容器。
6. 容器内放两个按钮：
   - “新增学生”：基础按钮，`id="addButton"`。
   - “删除学生”：危险样式按钮，`id="deleteButton"`。

B1 暂时不写自己的 JavaScript，不绑定事件。

## B1 验收

页面应显示一个标题和两个带 Layui 样式的按钮。老师检查结构和路径后，再发布 B2。

## B2：独立完成两个点击事件

继续修改 `03-day1-巩固练习.html`：

1. 确认 `<head>` 内容后有对应的 `</head>`。
2. 在页面底部已有的空 `<script>` 中调用：

```javascript
layui.use(["layer"], function () {
    // 初始化代码
});
```

这次使用完整形式：第一个参数声明需要 `layer` 模块，第二个参数是回调函数。

3. 在回调函数中取得 `layui.layer`，保存到 `layer` 变量。
4. 分别找到 `#addButton` 和 `#deleteButton`，保存为两个变量。
5. 分别注册点击事件：
   - 点击新增按钮：`layer.msg` 显示“新增学生”，配置 `icon: 1`、`time: 2000`。
   - 点击删除按钮：`layer.msg` 显示“删除学生”，配置 `icon: 2`、`time: 2000`。

限制：只使用一个 `layui.use`，两个点击事件都写在它的回调函数中。可以查看 Day 1 讲义，不复制旧练习文件。
