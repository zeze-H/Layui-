# Day 3-01：表单基本结构与输入框

## 一、表单解决什么问题

前两天的页面主要负责展示信息。表单负责让用户输入数据，例如新增学生时填写：

```text
学生姓名：张三
学生编号：2026001
```

表单不是一个输入框，而是一组相关输入项的整体。

## 二、最小表单结构

```html
<form class="layui-form">
    表单项目写在这里
</form>
```

拆开理解：

```text
form          HTML 表单标签，负责包住一组需要一起处理的数据
layui-form    Layui class，让内部表单元素使用 Layui 的表单规则
```

`form` 是 HTML 标签，`layui-form` 是 Layui 提供的 class。

## 三、一个表单项目的结构

```html
<div class="layui-form-item">
    <label class="layui-form-label" for="studentName">学生姓名</label>
    <div class="layui-input-block">
        <input
            id="studentName"
            name="studentName"
            type="text"
            placeholder="请输入学生姓名"
            class="layui-input"
        >
    </div>
</div>
```

父子关系：

```text
layui-form-item             一个完整表单项目
├── layui-form-label       左侧说明文字
└── layui-input-block      右侧输入区域
    └── input.layui-input  真正接收文字的输入框
```

各 class 的职责：

```text
layui-form-item    组织一行表单内容
layui-form-label   设置标签区域的布局
layui-input-block  设置输入区域的位置
layui-input        设置输入框外观
```

## 四、input 上的属性

### type

```html
type="text"
```

表示这是普通单行文本输入框。

### placeholder

```html
placeholder="请输入学生姓名"
```

输入框为空时显示提示文字。用户真正输入内容后，提示文字会消失。

### id

```html
id="studentName"
```

`id` 用于在当前页面唯一标识这个元素。这里的 `label` 通过：

```html
for="studentName"
```

与输入框的 `id="studentName"` 对应。点击“学生姓名”文字时，浏览器会把输入焦点放进对应输入框。

以后 JavaScript 也可以通过 `#studentName` 查找它。

### name

```html
name="studentName"
```

`name` 是这项表单数据的字段名。以后收集表单数据时，会形成类似：

```text
studentName: 张三
```

`id` 和 `name` 可以写成相同文字，但职责不同：

```text
id    在页面中识别具体元素，也可与 label 的 for 对应
name  收集或提交表单数据时使用的字段名
```

## 五、为什么输入框外面还有 input-block

`input` 只负责接收内容。`layui-input-block` 负责给输入框所在区域留出正确位置，使它与左侧标签对齐。

```text
label        左侧固定的说明区域
input-block  右侧可以放输入框、下拉框或其他控件的区域
```

以后把文本框换成下拉框时，外面的表单项目结构仍然可以保留。

## 六、按钮为什么先使用 type="button"

```html
<button type="button" class="layui-btn">保存学生</button>
```

`layui-btn` 负责外观，`type="button"` 表示它现在只是普通按钮。

真正的表单提交涉及提交行为、数据获取和验证。我们会在后续小节单独学习。本节按钮只用于完成页面结构，点击后暂时不执行操作。
