# Day 1 复习卡

## 今天掌握的完整流程

```text
HTML 创建元素
→ class 使用 Layui 样式
→ id 标识具体元素
→ 引入 layui.css 和 layui.js
→ layui.use 准备 Layui
→ document.querySelector 找到元素
→ addEventListener 监听事件
→ 点击后调用 layer.msg
```

## 来源分类

- HTML：`h1`、`button`、`div`、`class`、`id`。
- 浏览器 DOM API：`document.querySelector`、`addEventListener`。
- Layui：`layui.use`、`layui.layer`、`layer.msg`、`layui-btn*` 类。

## Layui 的通用调用形状

```javascript
模块.方法("普通参数", {
    配置名: 配置值
});
```

后面的日期、表格和弹层都会反复出现“取得模块、找到元素、调用方法、传配置、监听事件”。不要求默写，需要时回来看。

## 排错顺序

1. 页面元素有没有写出来？
2. CSS/JS 路径是否正确？
3. id 和 `#id` 是否一致？
4. 控制台是否报错？
5. 要延后执行的代码是否放在事件回调中？
