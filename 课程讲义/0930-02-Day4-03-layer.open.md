# Day 4-03：layer.open（自定义弹层）

## 它做什么

`msg` / `alert` / `confirm` 只能放一行文字；`layer.open` 让你自己决定框里放什么（标题、多行文字、表单、图片）。源码里 `msg`、`confirm` 内部都是调用 `open`，只是预设了配置，所以 `open` 是通用版本。

## 最小写法

```js
layer.open({
    type: 1,
    title: "班级说明",
    content: "<div class='layui-padding-3'><p>第一行</p><p>第二行</p></div>",
    area: ["400px", "200px"]
});
```

| 配置项 | 作用 |
| --- | --- |
| `type: 1` | 框里放自己写的 HTML；默认 0 是文字框 |
| `title` | 窗口标题 |
| `content` | 框里的内容（HTML 字符串） |
| `area` | 宽、高 |

- `content` 用双引号，里面的 HTML 属性用单引号，两种引号不会互相打断。
- `layui-padding-3` 是 Layui 自带的 CSS 类，`padding:16px`，让内容离窗口边缘 16 像素。
- `type:1` 的窗口右上角自带 ×。
- 触发方式：点击按钮 → 登记点击事件 → 事件函数里调用 `layer.open`。

## 逗号规则

判断方法：看同一层里后面还有没有下一项，有就加逗号，没有就不加。逗号只出现在三处：

1. 对象 `{ }` 里键值对之间（最后一项后面不加）；
2. 括号 `( )` 里参数之间，例如 `layui.use([...], function(){})`；
3. 数组 `[ ]` 里元素之间。

语句结束用分号；引号里的逗号只是文字。漏逗号会报 `Unexpected identifier` / `Unexpected token`。
