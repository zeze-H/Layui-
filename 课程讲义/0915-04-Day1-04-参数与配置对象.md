# Day 1-04：参数与配置对象

## 一、为什么先学这个

Layui 的大多数组件都通过“调用方法并传入配置”使用：

```javascript
layer.msg(...)
laydate.render({...})
table.render({...})
layer.open({...})
```

名字不同，但共同规律都是：

```text
对象.方法(参数)
```

理解参数和配置对象后，以后主要是在官方文档中查“可以配置哪些属性”。

## 二、方法调用

当前代码中：

```javascript
layer.msg("Hello,world");
```

- `layer`：弹层模块对象。
- `.`：使用对象中的功能。
- `msg`：显示消息的方法。
- `()`：调用方法，并把需要的数据放在圆括号中。
- `"Hello,world"`：传给方法的第一个参数。

参数可以理解为：调用一个功能时，交给它使用的数据。

## 三、多个参数

`layer.msg` 可以接收多个参数，参数之间使用逗号分隔：

```javascript
layer.msg("保存成功", {icon: 1});
```

这里有两个参数：

```text
第一个参数："保存成功"
第二个参数：{icon: 1}
```

第一个参数决定显示什么文字，第二个参数控制弹层的其他配置。

## 四、配置对象

```javascript
{icon: 1}
```

这是一个 JavaScript 对象。对象使用一对花括号表示，里面保存键和值：

```text
icon  → 键，也叫属性名
1     → 值
:     → 把键和值连接起来
```

可以读成：“把 icon 配置设置为 1”。

对象有多个配置时，用逗号分隔：

```javascript
{
    icon: 1,
    time: 2000
}
```

- `icon`：消息图标类型。
- `time`：显示时长，单位是毫秒。
- `2000` 毫秒等于 2 秒。

## 五、完整写法

```javascript
layer.msg("保存成功", {
    icon: 1,
    time: 2000
});
```

执行顺序可以理解为：

```text
调用 layer 的 msg 方法
↓
第一个参数提供消息文字
↓
第二个参数提供配置对象
↓
按照配置显示弹层
```

代码换行只是为了更容易阅读。下面两种写法含义相同：

```javascript
layer.msg("保存成功", {icon: 1, time: 2000});
```

```javascript
layer.msg("保存成功", {
    icon: 1,
    time: 2000
});
```

## 六、容易混淆的符号

```text
()  调用方法、存放参数
{}  创建对象，或者表示函数代码块
,   分隔多个参数或对象属性
:   分隔对象的属性名和值
;   表示一条 JavaScript 语句结束
```

花括号的含义要看位置：

```javascript
function () {
    // 这里是函数代码块
}
```

```javascript
{
    icon: 1
}
```

作为参数出现的这对花括号表示对象。

## 本小节练习

只修改点击函数中的 `layer.msg`：

1. 把显示文字改为“开始今天的学习”。
2. 传入第二个参数——配置对象。
3. 设置 `icon: 6`。
4. 设置 `time: 3000`，让消息显示约 3 秒。

最终仍然必须点击按钮后才显示消息。不要修改其他代码。
