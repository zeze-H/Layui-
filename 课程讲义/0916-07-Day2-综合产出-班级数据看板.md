# Day 2 综合产出：班级数据看板

## 一、产出目标

从空文件完成一个能展示、能响应窗口宽度、带导航下拉和按钮交互的“班级数据看板”。

这不是新课。除了把三等分推导成四等分，其他内容都来自 Day 1 和 Day 2。

最终页面包含：

```text
顶部导航
├── 概览（当前选中）
├── 学生中心
│   ├── 学生列表
│   └── 新增学生
└── 考勤管理

班级数据看板
├── 学生总数：45 人
├── 今日出勤：42 人
├── 请假人数：2 人
└── 缺勤人数：1 人

[查看今日出勤]
```

点击按钮后，弹出 Layui 消息：`今日出勤 42 人`。

## 二、本次要证明的能力

1. 能从空文件搭建 HTML 骨架并正确引入本地 Layui。
2. 能按照父子关系写导航和下拉菜单。
3. 能自己根据 12 栅格计算四等分。
4. 能区分列与卡片的职责。
5. 能把 DOM 查找、点击事件和 `layer.msg` 连起来。
6. 能把脚本放在页面内容之后，保证 DOM 已经建立。

## 三、四等分怎么推导

一整行是 12 格，现在需要放四张等宽卡片：

```text
12 ÷ 4 = 3
```

因此每个列使用：

```html
class="layui-col-xs12 layui-col-md3"
```

```text
窄窗口 xs12：一张卡片占满一行
宽窗口 md3 ：四张卡片各占 3/12
```

## 四、同时加载两个模块

这次导航需要 `element`，消息弹层需要 `layer`：

```javascript
layui.use(["element", "layer"], function () {
    const layer = layui.layer;
});
```

数组中可以写多个模块名。`use` 会准备两个模块，再执行回调函数。

这里不必写：

```javascript
const element = layui.element;
```

因为本练习只需要加载 `element` 处理已有导航，没有手动调用它的方法；而我们需要调用 `layer.msg`，所以把 `layui.layer` 保存到变量 `layer`。

## 五、正式任务

新建文件：`05-day2-综合练习.html`。

### 第一部分：页面基础

1. 自己写 HTML 基本骨架。
2. 在 `head` 中引入本地 `layui.css`。
3. 页面标题写“班级数据看板”。
4. 给 `body` 设置 `#f2f2f2` 背景。

### 第二部分：顶部导航

1. 创建 `layui-nav`。
2. “概览”是当前项目，添加 `layui-this`。
3. “学生中心”包含“学生列表”和“新增学生”两个子项目。
4. 第三个主项目是“考勤管理”。
5. 所有暂不跳转的链接使用 `href="javascript:;"`。

### 第三部分：内容区

1. 使用一个 `layui-container`。
2. 容器内写一级标题“班级数据看板”。
3. 创建带 `layui-col-space15` 的行。
4. 创建四个 `layui-col-xs12 layui-col-md3` 列。
5. 每列内部写一张具有 `header` 和 `body` 的 `layui-card`。
6. 四张卡片使用任务开头给出的文字和数字。

### 第四部分：按钮交互

在卡片行后写按钮：

```html
<button id="attendanceButton" class="layui-btn">查看今日出勤</button>
```

在所有页面内容之后、`</body>` 前：

1. 引入本地 `layui.js`。
2. 使用 `layui.use(["element", "layer"], 回调函数)`。
3. 在回调内取得 `layui.layer`。
4. 使用 `document.querySelector` 找到 `#attendanceButton`。
5. 给按钮监听 `click`。
6. 点击时调用：

```javascript
layer.msg("今日出勤 42 人", {
    icon: 1,
    time: 2000
});
```

## 六、自测清单

- 页面打开时控制台没有红色错误。
- 鼠标经过“学生中心”能看到两个子项目。
- 宽窗口显示四张并排卡片。
- 窄窗口显示四张上下排列的卡片。
- 点击按钮只在点击后弹出消息。
- `layui.css` 在 `head`，页面 HTML 在中间，`layui.js` 和自己的脚本在底部。
