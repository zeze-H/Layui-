# Day 3-03：必填验证、提交事件与表单数据

> 历史讲义：这份把多个新概念放在同一节，当前不按它做练习。请从 [阶段复习](0921-01-复习-把Day1到Day3前半段串起来.md) 开始，再依次学习 [03D](0921-02-Day3-03D-从普通按钮到提交按钮.md)、[03E](0921-03-Day3-03E-登记提交回调并留在页面.md)、[03F](0921-04-Day3-03F-看懂data-field.md)。

## 一、这一节要实现什么

当前“保存学生”只是普通按钮：

```html
<button type="button">保存学生</button>
```

这一节把它变成表单提交按钮，并实现：

```text
内容没填完整
→ Layui 提示必填
→ 不执行提交回调

内容填写完整
→ 执行提交回调
→ 取得姓名、编号、性别数据
→ 控制台显示数据对象
→ 弹出“表单验证通过”
```

本节只是前端模拟保存，不连接后端或数据库。

## 二、增加必填验证

给姓名输入框增加：

```html
lay-verify="required"
```

例如：

```html
<input
    type="text"
    id="studentName"
    name="studentName"
    placeholder="请输入学生姓名"
    class="layui-input"
    lay-verify="required"
>
```

学生编号和学生性别也增加同样的属性。

拆开理解：

```text
lay-verify    Layui 的表单验证属性
required      使用“必填”验证规则
```

`lay-verify` 不是标准 HTML 属性，而是 Layui 定义的自定义属性。

## 三、把普通按钮改成提交按钮

```html
<button
    type="submit"
    class="layui-btn"
    lay-submit
    lay-filter="studentSubmit"
>
    保存学生
</button>
```

四部分的职责：

```text
type="submit"              HTML：这是表单提交按钮
class="layui-btn"          Layui class：按钮外观
lay-submit                 Layui：这是由表单模块处理的提交按钮
lay-filter="studentSubmit" Layui：给这次提交事件一个识别名称
```

`lay-filter` 不是 CSS class，也不是表单数据字段名。它用于让 JavaScript 精确监听这一次提交事件。

## 四、监听 Layui 表单提交

在原来的 `layui.use` 回调中写：

```javascript
form.on("submit(studentSubmit)", function (data) {
    console.log(data.field);
    layer.msg("表单验证通过", {
        icon: 1,
        time: 2000
    });

    return false;
});
```

拆开理解第一行：

```text
form                  form 模块对象变量
on                    form 对象的事件监听方法
submit                监听提交事件
studentSubmit         对应 HTML 中的 lay-filter
function (data) {...} 提交通过验证后，由 Layui 调用的回调函数
```

对应关系：

```text
HTML：lay-filter="studentSubmit"
                  ↓ 名字必须相同
JS：form.on("submit(studentSubmit)", callback)
```

## 五、data.field 是什么

Layui 调用回调函数时，会把本次提交信息放进参数 `data`。

当前只使用：

```javascript
data.field
```

它是一个对象，保存当前表单中带有 `name` 的字段。

假如输入：

```text
学生姓名：张三
学生编号：2026001
学生性别：男
```

控制台中的 `data.field` 大致是：

```javascript
{
    studentName: "张三",
    studentNumber: "2026001",
    gender: "male"
}
```

对象中的键来自：

```text
input/select 的 name
```

对象中的值来自：

```text
输入框中填写的内容
或选中 option 的 value
```

这也说明 `name` 不是数据库字段本身，而是前端表单数据对象的字段名。后端以后再决定怎样接收和保存它。

## 六、为什么 return false

`type="submit"` 默认会让浏览器提交表单，通常会跳转或刷新页面。

当前没有真实服务器，我们只想在 JavaScript 中查看数据，所以回调最后写：

```javascript
return false;
```

它告诉 Layui：阻止这次表单的默认提交行为。

因此当前流程是：

```text
点击提交按钮
→ Layui 验证
→ 验证通过后执行回调
→ 查看 data.field
→ return false 阻止页面刷新
```

## 七、为什么同时加载 form 和 layer

```javascript
layui.use(["form", "layer"], function () {
    const form = layui.form;
    const layer = layui.layer;
});
```

```text
form   负责渲染、验证、提交事件和表单数据
layer  负责显示消息弹层
```

两个变量后面都会真正使用：

```text
form.render()
form.on(...)
layer.msg(...)
```

## 九、测试顺序

### 第一次测试：全部为空

直接点击“保存学生”。预期：Layui 提示必填，不显示“表单验证通过”。

### 第二次测试：只填写一部分

填写姓名但不填写编号和性别。预期：仍然提示未完成的必填项。

### 第三次测试：全部填写

填写所有内容后提交。预期：

- 页面不刷新；
- 弹出“表单验证通过”；
- 控制台出现包含 `studentName`、`studentNumber`、`gender` 的对象。
