# Day 1-05：Layui 类名组合与按钮

## 一、Layui 为什么主要使用 class

Layui 已经在 `layui.css` 中写好了许多样式。我们不需要重新写颜色、边框和尺寸，只要给 HTML 元素添加它规定的 class。

```html
<button class="layui-btn">默认按钮</button>
```

可以理解成：浏览器发现元素属于 `layui-btn` 这一类，就应用 Layui 为这一类准备的样式。

## 二、一个元素可以有多个 class

多个类名全部写在同一个 `class` 属性中，使用空格分开：

```html
<button class="layui-btn layui-btn-danger">删除</button>
```

这里不是一个很长的类名，而是两个类：

```text
layui-btn         基础按钮样式
layui-btn-danger  危险操作的颜色样式
```

浏览器会把两个类的样式组合到同一个按钮上。

## 三、基础类和修饰类

`layui-btn` 是基础类，先让元素成为 Layui 按钮。

其他类在基础按钮上修改某个方面，可以叫修饰类：

```text
layui-btn-primary  原始/朴素样式
layui-btn-normal   蓝色样式
layui-btn-warm     暖色样式
layui-btn-danger   危险操作样式
layui-btn-lg       大型按钮
layui-btn-sm       小型按钮
layui-btn-xs       迷你按钮
layui-btn-radius   圆角按钮
layui-btn-fluid    宽度自适应父容器
```

例如，同时组合基础、颜色、尺寸三个类：

```html
<button class="layui-btn layui-btn-danger layui-btn-sm">删除</button>
```

## 四、为什么不只写修饰类

下面通常是不完整的：

```html
<button class="layui-btn-danger">删除</button>
```

`layui-btn-danger` 只负责修改某部分外观，按钮的基础结构来自 `layui-btn`。因此一般先写基础类，再追加修饰类。

这是一种常见的 CSS 设计方式：

```text
基础类 + 颜色类 + 尺寸类
```

## 五、按钮容器

多个按钮放在一起时，可以使用：

```html
<div class="layui-btn-container">
    <button class="layui-btn">新增</button>
    <button class="layui-btn layui-btn-normal">编辑</button>
    <button class="layui-btn layui-btn-danger">删除</button>
</div>
```

`layui-btn-container` 用于组织一组按钮及其间距。

## 六、按钮文字为什么要体现用途

后台系统中常见约定：

```text
新增、保存：默认色或 normal
取消、普通操作：primary
删除、危险操作：danger
```

颜色不只是装饰，也在提示操作含义。危险操作仍需要确认弹层，不能只依赖红色。
