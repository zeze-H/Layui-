# Day 2-04：顶部导航基础

## 一、导航解决什么问题

后台页面不只有仪表盘，还可能有学生管理、课程管理等页面。顶部导航负责告诉用户有哪些主要区域，以及当前位于哪个区域。

这一节先做静态导航，只学习结构和样式。下拉菜单与 JavaScript 留到后面单独学习。

## 二、导航的 HTML 骨架

```html
<ul class="layui-nav">
    <li class="layui-nav-item layui-this">
        <a href="javascript:;">首页</a>
    </li>
    <li class="layui-nav-item">
        <a href="javascript:;">学生管理</a>
    </li>
    <li class="layui-nav-item">
        <a href="javascript:;">课程管理</a>
    </li>
</ul>
```

先分清哪些属于 HTML，哪些属于 Layui：

```text
ul、li、a                 HTML 标签
layui-nav                Layui 导航容器 class
layui-nav-item           Layui 导航项目 class
layui-this               Layui 当前选中状态 class
```

## 三、为什么使用 ul、li、a

导航本质上是一组链接，因此适合使用列表结构：

```text
ul：整组导航列表
li：一个导航项目
a ：用户可以点击的链接
```

父子关系是：

```text
ul.layui-nav
├── li.layui-nav-item
│   └── a
├── li.layui-nav-item
│   └── a
└── li.layui-nav-item
    └── a
```

Layui 通过这些 class 给原本普通的 HTML 列表添加导航外观。

## 四、layui-this 是什么

```html
<li class="layui-nav-item layui-this">
```

同一个 `li` 同时有两个 class：

```text
layui-nav-item：它是一个导航项目
layui-this：它是当前选中的导航项目
```

本节把“首页”设为当前页面，因此只给首页所在的 `li` 添加 `layui-this`。

## 五、href="javascript:;" 是什么

`a` 标签通常通过 `href` 跳转到另一个页面。我们还没有创建那些页面，所以先写：

```html
href="javascript:;"
```

它在这个练习中表示“暂时不跳转”。这是临时占位写法，不是 Layui 属性。以后有真实页面时，应换成真实地址。
