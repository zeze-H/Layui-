# Day 3-03E：登记提交回调，并让页面留下来

开始条件：上一节的空白必填提示已验收。这节只让“填写完整 → 执行一句代码 → 页面不跳转”发生；暂时不读表单数据。

## 先区分两个事件

Day 1 的按钮是：

```javascript
button.addEventListener("click", handleClick);
```

意思是“浏览器以后发现这个按钮被点击，就调用 `handleClick`”。它关心的是**点击**。

Layui 表单则是：

```javascript
form.on("submit(studentSubmit)", handleStudentSubmit);
```

意思是“Layui form 以后发现名为 `studentSubmit` 的提交并通过验证，就调用 `handleStudentSubmit`”。它关心的是**通过验证的表单提交**，不是所有点击。`submit(studentSubmit)` 整体是传给 `form.on` 的事件名字符串；其中 `studentSubmit` 必须与 HTML 的 `lay-filter="studentSubmit"` 一致。

## 为什么先写有名字的函数

先在 `layui.use` 的函数内部写：

```javascript
function handleStudentSubmit() {
    console.log("提交回调执行了");
    return false;
}
```

这是**定义**函数：浏览器先保存它，暂时不运行。然后登记：

```javascript
form.on("submit(studentSubmit)", handleStudentSubmit);
```

这里传的是 `handleStudentSubmit`，没有 `()`。如果写成 `handleStudentSubmit()`，就是现在立刻执行函数，再把执行结果交给 `form.on`，时机错了。你之前给 `layui.use` 传 `afterModulesReady` 时，规则相同。

## `return false` 的准确作用

提交按钮仍有 HTML 原生提交行为。我们现在只在前端练习，不把数据交给服务器；在 Layui 的提交回调里 `return false`，Layui 就会阻止默认的表单跳转。它不是“停止所有 JavaScript”，也不会自动保存到数据库。它只在**这个由 Layui 调用的提交回调**里起到这里的作用，不能随处照抄。

## 这节只加两处代码

继续修改复习页，在原来 `layui.use(["form", "layer"], function () { ... })` 的内部：

1. 写上面的 `handleStudentSubmit` 函数。
2. 在 `form.render()` 后登记 `form.on("submit(studentSubmit)", handleStudentSubmit);`。旧的普通按钮点击事件保留，不必重新写。

完整测试顺序：

```text
空白点击保存 → 必填提示；控制台没有“提交回调执行了”
填姓名、选性别再点击保存 → 控制台出现那句话；页面不刷新
点击查看填写说明 → 原来的短消息仍然出现
```

如果空白也执行了回调，先检查 `lay-verify` 写在哪个控件上；如果填写完整后页面刷新，先检查 `return false` 是否写在 `handleStudentSubmit` 里面。通过后再读回调参数。官方依据：[Layui form 提交事件](https://layui.dev/docs/2/form/)。
