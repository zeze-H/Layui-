```text

回调函数参数 data

```

代码写对不等于已经理解。现在保留它作为最终对照，重新从浏览器原生表单开始，先回答：**如果完全没有 Layui，表单自己会做什么？**

## 一、最小 HTML 表单

```html
<form>
    <label for="studentName">学生姓名</label>
    <input
        type="text"
        id="studentName"
        name="studentName"
        required
    >
    <button type="submit">保存学生</button>
</form>
```

这一段没有任何 Layui，也没有 JavaScript。

## 二、先只看父子结构

```text
form                    整张表单
├── label               输入框的说明文字
├── input               用户填写数据
└── button              提交按钮
```

`form` 把输入框和按钮包在一起，因此浏览器知道：点击这个提交按钮时，要处理这张表单中的数据。

## 三、四个属性各负责什么

```text
type="text"      这是文本输入框
id="studentName" 在页面中标识这个具体输入框
name="studentName" 提交数据时使用的字段名
required         HTML 原生必填规则
```

`required` 是标准 HTML 属性，不是 Layui 的 `lay-verify="required"`。

## 四、type="submit" 做了什么

```html
<button type="submit">保存学生</button>
```

这里没有 JavaScript 方法调用。`type="submit"` 只是告诉浏览器：

> 点击这个按钮时，执行它所在 `form` 的默认提交行为。

浏览器默认流程：

```text
点击 submit 按钮
→ 检查 required
→ 收集带 name 的表单控件
→ 按浏览器默认方式提交
→ 当前页面通常会跳转或刷新
```

这就是后面需要“阻止默认提交”的原因。必须先知道默认行为存在，`return false` 才不会变成需要死记的神秘代码。
