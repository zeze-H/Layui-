# 综合练习：从空文件做一页学生信息录入

开始条件：复习课和 Day3-03D/E/F 都已分别验收。这是**学完后的产出**，现在先知道终点即可，不要提前写。不会增加新 API，也不要求背类名；你可以查看旧代码和讲义。

## 想做成什么

一个简化的学生管理页：顶部导航；主内容区有“班级概况”卡片和“新增学生”卡片；宽屏并排、窄屏上下；表单有姓名、学号、性别；普通说明按钮点击显示 `layer.msg`；保存按钮空白时提示必填，填完整后在控制台打印本次字段对象、页面不刷新，同时显示一条“已收到表单数据”的消息。这里的“收到”只指浏览器前端，不假装已经保存进数据库。

## 自己分四段完成

新建 `10.综合-学生信息录入.html`。每段完成就运行一次，别一次写到底。

1. **页面和布局**：HTML 骨架、本地 Layui CSS/JS、导航、`container`、`row`、两列、两张卡片。先只确认宽屏并排、窄屏上下。
2. **表单结构**：在第二张卡片中写 `layui-form`；姓名、学号输入框；性别 `select`；普通说明按钮 `type="button"`、保存按钮 `type="submit"`。核对每个 `label for` / 控件 `id`，以及三个控件各自的 `name`。先别写提交事件。
3. **已会的交互**：`layui.use(["form", "layer"], ...)` 中取得模块对象、`form.render()`；给说明按钮用 DOM 查找与 `addEventListener`，点击调用 `layer.msg`。确认页面打开时没有自动弹消息。
4. **提交**：给三个控件加 `lay-verify="required"`，保存按钮加 `lay-submit` 和 `lay-filter`；用一个有名字的函数做 `form.on("submit(你的filter名)", 函数名)` 的回调。回调里输出 `data.field`、调用 `layer.msg("已收到表单数据")`，最后 `return false`。确认空白不进入回调、完整填写才进入、页面不刷新。

## 完成标准

- 你能分别指出 HTML 默认行为、DOM 点击监听、Layui 表单提交监听。
- 你能从页面中的 `name`、用户输入、`option value` 推出 `data.field` 的键和值。
- 你能说明为什么回调最后写 `return false`，也知道这个练习并未真正存库。
- 遇到错误会先查资源路径、HTML 父子结构、`id` / `#id`、`lay-filter` 两处文字是否一致、控制台报错，而不是随机改代码。
