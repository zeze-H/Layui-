# Day 1-03：点击按钮执行函数

## 一、什么是事件

网页不会只从上到下执行一次。用户还会点击、输入、选择和提交，这些发生在页面上的动作叫“事件”。

常见事件：

```text
click   点击
input   输入内容
change  内容改变
submit  提交表单
```

这节课只学习 `click`。

## 二、addEventListener 是什么

我们已经把按钮保存到了 `button` 变量：

```javascript
var button = document.querySelector("#startButton");
```

按钮对象提供了 `addEventListener` 方法，用于监听事件：

```javascript
button.addEventListener("click", function () {
    // 点击后执行的代码
});
```

逐段理解：

- `button`：要监听的按钮对象。
- `.`：使用按钮拥有的方法。
- `addEventListener`：添加事件监听器。
- `"click"`：监听点击事件。
- `function () { ... }`：点击之后才执行的函数。

整句可以读成：

```text
给 button 添加一个 click 监听器；发生点击时，执行这个函数。
```

## 三、为什么传入的是函数

下面两件事发生的时间不同：

```javascript
layer.msg("Hello,world");
```

代码执行到这里就立即弹出。

```javascript
function () {
    layer.msg("Hello,world");
}
```

这里只是先准备好一段代码，没有立即调用。浏览器会在按钮被点击时调用它。

这种“先交给别处，之后满足条件再执行”的函数，常被称为回调函数。现在理解执行时间即可，不要求背术语。

## 四、执行流程

```text
页面加载
↓
找到按钮
↓
给按钮登记 click 监听器
↓
页面等待用户操作
↓
用户点击按钮
↓
浏览器执行回调函数
↓
layer.msg 显示消息
```

## 五、为什么把代码放进同一个 layui.use

你现在有两个自定义 `<script>`：第一个取得 `layer`，第二个取得 `button`。下一步把它们整理在一起：

```javascript
layui.use(function () {
    var layer = layui.layer;
    var button = document.querySelector("#startButton");

    button.addEventListener("click", function () {
        layer.msg("Hello,world");
    });
});
```

这样，点击函数既能使用 `button`，也能使用同一个函数内部的 `layer`。这也避免了变量作用范围造成的混乱。

## 六、HTML 中的正确顺序

```text
标题和按钮
↓
自定义 script
↓
结束 body
```

Layui 的库文件已经在 `<head>` 中引入，可以保留。自己的调用代码只保留一块，并放在按钮后面。
